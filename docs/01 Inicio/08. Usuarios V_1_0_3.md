# 08. Usuarios V_1_0_3.md

### 1. Matriz de Roles y Actores

| Rol / Actor | Tipo de Interacción | Descripción del Perfil y Responsabilidades |
| --- | --- | --- |
| **Administrador del Sistema** | Directa (Web Desktop) | Usuario de TI en DistriRápido S.A.C. Gestiona usuarios, roles y parámetros. |
| **Operador de Logística** | Directa (Web Desktop) | Usuario operativo principal. Importa pedidos, ejecuta VRPTW, monitorea mapa y re-optimiza. |
| **Conductor de Reparto** | Directa (PWA Mobile) | Personal de campo en Huancayo, El Tambo y Chilca. Consulta hoja de ruta y registra entregas. |
| **Gerente de Operaciones** | Directa (Web / Dashboard) | Usuario estratégico. Consulta KPIs de ahorro de distancia, combustible y CO₂. |
| **Cliente Final (Bodegas)** | Indirecta (Web Tracking) | Destinatario en Huancayo, El Tambo y Chilca. Consulta el ETA de su pedido mediante enlace web. |
| **Auditor Académico / Docente** | Directa (Web Desktop) | Equipo evaluador de la Universidad Continental. Audita el sistema y la trazabilidad **exclusivamente en modo lectura/consulta** (ver nota de corrección abajo). |

> **Nota de corrección (V_1_0_3):** Por la naturaleza del rol, el Auditor Académico/Docente se limita estrictamente a **lectura, consulta, revisión y reportes**. No cuenta con permisos de ejecución sobre procesos operativos (VRPTW, re-optimización), a diferencia de versiones anteriores.

### 2. Historias de Usuario (HU) y Trazabilidad

* **HU-01:** Como *Operador*, quiero *importar pedidos en CSV*, para *cargar lotes de entregas en Huancayo, El Tambo y Chilca* (Trazado con `MRF-02` / `RF-004`).
* **HU-02:** Como *Operador*, quiero *ejecutar el algoritmo VRPTW*, para *obtener rutas eficientes respetando ventanas de tiempo* (Trazado con `MRF-03` / `RF-007`).
* **HU-03:** Como *Conductor*, quiero *ver mi secuencia de paradas en pantalla táctil simplificada*, para *navegar la ruta sin distracciones* (Trazado con `MRF-04` / `RF-010`).
* **HU-04:** Como *Conductor*, quiero *registrar entregas en modo offline*, para *no perder datos cuando transite por zonas sin señal* (Trazado con `MRF-04` / `RF-012` y `RNF-003`).
* **HU-05:** Como *Gerente*, quiero *visualizar el ahorro de CO₂ en el Dashboard*, para *evaluar las metas de sostenibilidad* (Trazado con `MRF-05` / `RF-014`).
