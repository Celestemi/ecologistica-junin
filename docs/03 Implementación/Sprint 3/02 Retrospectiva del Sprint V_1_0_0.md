# Retrospectiva del sprint

**Versión documental:** V_1_0_0

**Nombre del Proyecto:** EcoLogística Huancayo — Optimizador de Rutas Sostenibles para DistriRápido S.A.C.

**Líder del Proyecto:** Nikole Celeste Bastidas Vilca (Project Manager)

## Resultado del sprint

El sprint cumplió los requisitos definidos para la entrega. La solución desarrollada quedó validada con pruebas automatizadas, verificación funcional, calidad de código y evidencias de operación en el entorno de validación.

La entrega evidencia que la funcionalidad principal del sprint fue implementada y probada con resultados satisfactorios. Los indicadores clave del proyecto muestran que los objetivos del sprint quedaron cubiertos dentro del alcance establecido.

## ¿Qué se logró?

- Se consolidó la visualización y el análisis de rutas en mapa interactivo.
- Se validó la consulta de detalle por parada y la navegación entre elementos de la ruta.
- Se incorporó la vista alternativa tabular para escenarios de degradación o fallas del mapa.
- Se integraron los KPIs operativos y ambientales con cálculo y presentación de resultados coherentes.
- Se verificó la comparación contra línea base y la proyección de árboles equivalentes.
- Se implementó la persistencia offline y la sincronización de entregas con manejo de idempotencia.
- Se dejó evidencia de validación automatizada y de revisión de calidad aplicando buenas prácticas de seguridad y accesibilidad.

## ¿Qué aprendimos?

- La entrega del sprint fue posible gracias a la validación continua y a la integración entre backend, frontend y pruebas automatizadas.
- La trazabilidad entre requisitos, implementación y pruebas permitió cerrar con evidencia el cumplimiento del alcance.
- Los ajustes funcionales y de experiencia de usuario fueron incorporados de forma consistente con la intención del producto.
- Se mantiene el enfoque en mejora continua, pero sin compromisos de alcance ni evidencia de incumplimiento del sprint.

## ¿Qué seguimos mejorando?

- Continuar reforzando la automatización de pruebas end-to-end para escenarios críticos.
- Mantener la revisión de accesibilidad y seguridad como parte del flujo de desarrollo.
- Documentar y reforzar la mejora de procesos para siguientes iteraciones.
- Consolidar métricas de operación y seguimiento para futuras entregas.

El resultado general del sprint es positivo: se cumplieron los requisitos previstos y la solución quedó lista para continuar con la siguiente etapa del proyecto.
