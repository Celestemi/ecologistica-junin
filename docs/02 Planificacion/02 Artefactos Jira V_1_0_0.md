# 02 Artefactos Jira V_1_0_0

## Informe de evidencia visual y funcional de la parametrización de Jira Software

**Proyecto:** EcoLogística Huancayo  
**Herramienta:** Jira Software  
**Metodología:** Scrum  
**Versión del documento:** V_1_0_0

---

## 1. Objetivo del documento

El presente documento reúne las evidencias visuales y funcionales de la parametrización realizada en Jira Software para el proyecto **EcoLogística Huancayo**.

Las evidencias permiten verificar la configuración de los principales artefactos utilizados para la planificación y gestión del proyecto mediante Scrum: **Roadmap, Backlog, Sprint Planning, Tablero Scrum y Gestión de Versiones/Release**.

### Política de capturas de pantalla

Las evidencias se presentan recortadas al área funcional de Jira que corresponde a cada elemento demostrado, evitando incluir escritorio, barras de tareas del sistema operativo, pestañas del navegador o espacios innecesarios.

- Épicas identificadas mediante códigos `ELH-1` a `ELH-8`.
- Distribución temporal de las épicas.
- Asociación de las épicas con los principales módulos funcionales del proyecto.
- Versiones principales del producto representadas en la línea de tiempo.

# 4. Conclusión

Las evidencias presentadas permiten verificar la parametrización de los principales artefactos de Jira Software utilizados para la gestión Scrum del proyecto **EcoLogística Huancayo**.

En conjunto, se evidencia una estructura que permite:

1. Planificar el producto mediante **épicas y roadmap**.
2. Organizar y priorizar el trabajo mediante el **backlog**.
3. Seleccionar y estimar el trabajo de un **Sprint**.
4. Gestionar visualmente el flujo de desarrollo mediante el **tablero Scrum**.
5. Organizar las entregas mediante **versiones/releases**.

Por tanto, las cinco evidencias documentan los elementos principales necesarios para demostrar la configuración funcional de Jira como herramienta de apoyo a la gestión del proyecto bajo Scrum.
